# 深坑拼街完整桌遊規則書

這是完整規則書的 HTML 網頁版，包含 13 個章節區段、72 張板塊索引、插圖及桌邊速查。這份檔案包是規則書，不是遊戲程式。

## 上傳 GitHub Pages

1. 解壓縮檔案包，將 `index.html`、`.nojekyll` 和此 README 放到你的 GitHub 儲存庫根目錄並提交。不要只上傳 ZIP。
2. 在儲存庫開啟 Settings → Pages。
3. 在 Build and deployment 的 Source 選 Deploy from a branch。
4. 選擇放有檔案的分支（通常是 main），資料夾選 /(root)，按 Save。
5. 等 GitHub Pages 部署完成，從 Pages 設定頁開啟它顯示的網址。

若儲存庫已有 index.html（例如遊戲首頁），請將本規則書 index.html 改名為 rules.html 再上傳，避免覆蓋原首頁；發布後在原網站網址後加 /rules.html 即可。

所有插圖、樣式與腳本都內嵌在 index.html，不必另傳圖片，也不需安裝套件或建置。可直接在電腦雙擊開啟。支援手機閱讀、章節目錄與瀏覽器列印。公開儲存庫和 Pages 網站會公開內容，請自行確認分享範圍。

GitHub 官方說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

規則依使用者提供的深坑拼街 v0.7 原型整理。未定義部分明確標示為試玩約定；本檔案包未替你建立儲存庫或上傳發布。
